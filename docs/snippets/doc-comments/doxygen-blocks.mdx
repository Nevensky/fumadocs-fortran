Reads a matrix from a file in the Matrix Market format.

**Formats**

- `coordinate`: an entry a line, for sparse matrices
- `array`: every entry, column by column

A file of the first kind starts so:

```text
%%MatrixMarket matrix coordinate real general
  3 3 2
  1 1 4.0
  3 2 -1.5
```

A program reads it with

```f90
call read_market('a.mtx', a, info)
```

The format is described in \[boisvert1997\] and on [its home page](https://math.nist.gov/MatrixMarket/); [`write_market`](#ex-doxygen-blocks-write_market) writes it.<br /> Comments in the file are skipped.
